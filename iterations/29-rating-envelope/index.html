    Questions
    1. How does this help draw a system or a single-line diagram?
    It feeds the feeder (circuit) annotations at a busbar, never a busbar figure. On a single-line diagram each circuit leaving a busbar carries its own rating label; at() supplies it per circuit as circuits[].ratings_mva (read from the record fields winter_mva, spring_mva, summer_mva, autumn_mva), with circuits[].flags for placeholders and by_season.lowest_circuit_mva / highest_circuit_mva as a range. No busbar total is drawn because, in the module's words: It draws no transformer, cable route, protection or earthing.
    2. What is this code used for?
    Module engine/rating-envelope.js, ventus-grid-engine commit ; exported function at(index, key, options) (source line 86) with exports . It was promoted from gridatlas atlas/modules/202609012250-rating-envelope.js (its header, lines 4–20). Caller in the estate, read from source: the gridatlas SLD sandbox cartridge atlas/cartridges/202609012345-sld-sandbox-v9-8.js (gridatlas commit 06e0a1444caf) calls mod.at(topology.index, point.site_code, …) at line 3770 and prints a "Circuit ratings" card at line 3784 that states the figures are not added together. Later sld-sandbox and substation-intelligence cartridges carry an embedded copy registered as ratingEnvelope (name-match inference; not every call site was read).
    3. Where does it lead next?
    To conductor current: engine/current-from-power.js currentFromMvaAtKv({ mva, kv, phases }), whose own comment (lines 131–133, same commit) says "This is the call a rating-envelope result feeds". No code at this commit wires the two together (searched by name), so the link is the comment's statement, not an established call.

    Line colours are the Grid Atlas v8 topology colours (repd_grid_atlasv8 layer config: 400kV, 275kV, 220kV, 132kV, 66kV, 11kV); each end of a line takes the colour of the voltage its node declares, and substations are white as the Atlas draws them. A node with no declared voltage, a season with no published value, and a value the module flags as a placeholder are drawn grey.
