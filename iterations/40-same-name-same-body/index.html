SAME NAME, SAME BODY?

Two kinds of repetition in the estate's code, kept apart. Same name: function families that carry one recorded name. Same body: families whose ordered sequence of permanent line numbers is identical. One line number is one distinct line of text, so an identical sequence is identical code in the same order. Everything below is counted in your browser from the numbered database the wafer loads.

THE FOUR CASES

same name, same body · true copies—
different names, same body · renamed copies—
same name, different bodies · a name hiding different code—
unique name, unique body—
no name recorded · "(anonymous)"—

Each family is counted once, in the first case that fits, in the order listed. "(anonymous)" is a placeholder for code with no name, so it cannot share a name and is counted apart. Bars are families, not verdicts.

    1. How does this help draw a system or a single-line diagram?
    It draws no busbar, feeder, transformer, cable route, protection or earthing itself: none yet. What it guards is the drawing. A distance or voltage-drop function copied into two places and edited in only one will give two answers, and the same diagram drawn twice may disagree; a name shared by different bodies may hide different physics behind one word. Names in the estate that sound like drawing physics, with their distinct bodies (name-match inference): not yet known.

It reads families.json fields name, lineOffset, lineCount, files, repos, block, n and lines.bin, from the numbered database not yet known. The selected group's code sits in register blocks not yet known: pick a name (the family's block field).

    Machine detail · not yet known: tick Compare every family.

    Loading, as Grid Atlas does it: every layer starts unticked and unfetched; ticking fetches its files through one queue of at most 3 requests, each with a 15 s timeout; a file is fetched once and shared; a failed fetch is retried by ticking again; unticking hides and keeps the data. The comparison runs in a Web Worker, so the page scrolls while it counts. Each source is one whole file, so there are no tiles: the ground is one GPU draw of the numbered lines, and only the selected name's lines are lit, and only those inside the view. Rows, legend and card exist once and are re-filled; no element is created per line or per family. Body colours come from one fixed palette in body order; bodies outside the coloured page are drawn grey.
