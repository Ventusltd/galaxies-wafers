HIDDEN WIRES

A hidden wire is a need a part never declared, found by unplugging or swapping parts and watching what breaks. Each dot is a block in the public block register. Each dashed wire is a recorded failure that names the module the failing part needed, drawn from that part to the module, as thick as the number of compositions that failed on it. Solid cased lines are the needs the register declares.

WAIT — nothing is fetched until you tick a layer. Tick Hidden wires to begin.

1. How does this help draw a system or a single-line diagram?
It draws no busbar, feeder, transformer, cable route, protection or earthing itself. It shows why the part that draws the single-line panel stops before drawing anything. In gridatlas commit ece848117a6d, atlas/cartridges/202609080850-sld-sandbox-v9-8.js throws sld-sandbox requires the sld-styles module at line 1581 when window.__GRIDATLAS_MODULES__.sldStyles is absent; that module's sldPanel(PANEL_ID) (atlas/modules/202609040400-sld-styles.js line 213) is the SLD panel's stylesheet, installed at sandbox line 7614. The same cartridge's grid-scope module throws grid-scope requires the geodesy module at line 46; geodesy supplies the distances for the sandbox's straight lines to the nearest mapped substations (lines 1653–1659), which the sandbox itself says are not cable routes (line 1566). The wire data field is compounds[].decays[].text; its thickness is the count of compounds[] carrying that text.

Loading, as Grid Atlas does it: every layer starts hidden and unfetched; ticking it fetches its files through one queue of at most 3 requests, each with a 15 s timeout; a file shared by two layers is fetched once; a failed fetch can be retried by ticking again; unticking hides and keeps the data. Each source is one whole file, so there are no tiles: at most 5 files are ever fetched (block register, compounds, graph, legend, cvaa listing). Drawing touches only dots and lines inside the view; the line under the plane says how many were drawn in the last frame. No DOM element is created per wire, line or dot.
