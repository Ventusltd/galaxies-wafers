THE MAP BUTTON, ROUND TRIP

Pipeline News puts a MAP ↗ button on a project record. It is a deep link: a URL that carries the project's identity into Grid Atlas. This page runs the estate's own contract module, deeplink/contract.js, in your browser, and shows the link surviving and failing.

1 · ROUND TRIP

For every bucket in the module's BUCKETS: a synthetic record (not a real project) goes through buildDeepLink, then parseDeepLink. Each field is compared with ===.

    2 · RECEIVERS

    From deeplink/receivers.json at the same commit. Nothing is fetched until you tap. Queue of 4, 15 s timeout each, GET with no cache. The status is measured now, in your browser.

      3 · BREAK IT

      Edit the link by hand. The page runs parseDeepLink on each change, then asks buildDeepLink to rebuild it, and reports what the module refuses, drops or lets through.

      4 · MAP BUTTON

      Pick a synthetic record. The button opens the canonical receiver with the link buildDeepLink(record) returns. The identity is synthetic, so the receiver's register lookup should not find it: that is the honest arrival for made-up data.

      Questions
      How does this help draw a system or a single-line diagram?
      It draws no busbar, feeder or transformer itself. It carries a project's identity (repd_ref) and its point (latitude, longitude, zoom) to the map, where the receiver draws the project's connection: the measured line to the nearest mapped transmission substation (canonical.computes in receivers.json). The technology field picks which map layer is switched on, through layerIdForBucket.
