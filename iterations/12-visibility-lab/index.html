Questions

How does this help draw a system or an SLD?

It tests whether a code-layer point or route can be distinguished. It draws no busbar, feeder, transformer, protection or earthing element. features[].keys feeds frozen place(key); these are code addresses, not electrical coordinates.

What is this code used for?

currentStyle, proposedStyle and measureStyle provide the style model; this page calls them directly. Baseline widths and opacity come from layers-panel.mjs / drawOverlay. Placement comes from unchanged wafer.mjs / place. Other callers have not been established here; module titles do not prove runtime calls.

Where does it lead next?

The exported JSON can feed a layer renderer by layer ID. No live renderer integration, complete module coverage, or key-to-source-body mapping is established by this comparison. Antialiasing, overlap, bright substrate points and physical phone conditions need separate review.

Machine detail

Loading source identity…

Refusals: unknown layer, malformed geometry, unissued keys during export, mismatched file digest or feature count. Empty layers create no marks. Geometry is loaded only on selection, one request at a time; obsolete requests are cancelled. No all-layer geometry preload.
