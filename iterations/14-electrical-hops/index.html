      Questions
      How does this help draw a system or a single-line diagram?
      between(...).path supplies ordered node-to-node connections and their circuit/transformer kind. This page draws the synthetic fixture and highlights that returned path. It does not create a certified single-line diagram or locate a real asset.
      Which functions own the result?
      network-topology.index(product) constructs the current graph; electrical-distance.between and within perform the searches. Their full source pin is below. The page owns schematic positions, colours, formatting and animation only; it does not reimplement breadth-first search.
      What can I connect next?
      No real connection is established. A returned path says nothing about spare capacity, permissible loading or approval. No impedance or seasonal MVA values are summed. The9999MVA fixture placeholder remains unchanged in a returned hop and must not be treated as headroom.
      What does the origin-voltage filter mean?
      It filters starting nodes only. A132kV origin may traverse the transformer and continue at400kV. An undeclared voltage is not inferred from a node's name; absence of a reported change is not proof that two unknown voltages match.
      What can the search omit?
      Paths outside the selected hop budget, refused edges and planned changes. One proposed2029edge to FUTR1 is excluded; FUTR1 is not a current fixture node. Additional destination-node ties are not a count of every shortest path.

        Data-only fixture · Lab contract

        The five site names are proof identifiers, not an assertion about real substations. Inputs: origin and destination site identifiers, integer hop budget0–6 (interface policy), optional positive origin kV. Outputs: ordered hops, refusals and nearby site counts. Transformer traversal counts as one hop. Source schema mismatch or unknown site can return null; the source is not a comprehensive malformed-data validator.

        Per-hop seasonal ratings are MVA; impedance fields are percentages on a100MVA base, carried without combination. A path is neither kilometre distance nor impedance distance nor power flow. The source's own proof is a verified static caller at this pin; cross-repository callers have not been exhaustively audited.
